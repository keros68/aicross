# TASK-66 探测说清原因、指定路径、模式说明

用户 10-28 反馈：
- pi 装在 PATH 以外的目录，没走启动脚本打开 aicross 时，重新探测后 pi 整张卡片折叠进「未安装」，只看到「pi 没了」。
- pi 下的模型都验证失败后，「全部测试」按钮消失，用户以为功能被删了。
- 不同模式不好理解。

## 要做

1. 找不到 agent 时说清原因
   - 未安装的说明写明找过什么：「没找到 pi；安装后重新探测，或指定路径」。指定的路径不存在时写「指定的路径不存在：<路径>」。
   - 资源库里还留着模型（以前探测到过）的 agent 不折叠进「未安装」，留在主列表里显示状态与说明。
2. 指定路径
   - 资源库每个 agent 可记一个用户指定的可执行文件路径（`customPath`）。探测、派发、冒烟找可执行文件时先用它，文件不存在时退回原有查找。
   - 命令行 `aicross resources set-path <agent> [<路径>]`，不给路径即清除；路径必须是已存在的文件。窗口在 agent 卡片与未安装行给「指定路径」，已指定时显示路径与「清除」；保存后重新探测。
3. 按钮置灰不隐藏
   - 有第三方模型的 agent 卡片始终显示「全部测试」；没有待测模型时置灰，提示「没有待测的模型」。
4. 模式说明
   - 内置模式卡片在名称下写一句「适合……」，旁边标「只读」或「改项目文件」；原有机制说明放进悬停提示。
   - 自定义模式仍显示用户写的介绍；「只读 / 改项目文件」按位置的写入方式推出。
   - `docs/MANUAL.md` 模式表补齐六个模式，用途与界面一致。

## 完成条件

- 单元测试：指定路径的读写与优先级、未安装说明、未安装 agent 的分组、全部测试按钮的状态、模式说明与写入方式推断。
- 真机：把本机 pi 的指定路径设到一个 PATH 以外的副本，探测得到 pi；清除后恢复原状。
