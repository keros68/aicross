# fix-51-r1 外观改为 magpie 风格（用户 10-06）

用户：「UI 可以学一下 https://github.com/yetone/magpie」。参照截图在 `tasks/ref-magpie/`（`agents-light.png`、`usage-light.png`、`picker-light.png`、`panel-light.png`），先用 Read 逐张看。功能、命令与数据流不变（含 TASK-51 刚做的主 agent、skill 页、一键推荐），只改外观与交互形态。界面仍然只放名称、数据与动作，不写说明句。

## 要学的东西

1. **整体**：浅灰底（浅色约 `#f4f4f6`），内容放在大号白色圆角卡片里（圆角约 16px，1px 很浅的边），**一张卡片里多行，行之间用细分隔线**，不再一行一张卡片。字号略大（正文 15px），留白更足。
2. **顶栏**：左上 logo + 「aicross」；正中是分段切换的导航（资源 / skill / 模式 / 派发记录），选中项白底；右上只放图标按钮（刷新 = 重新读取当前页、窗口按钮）。去掉左侧导航栏。
3. **主 agent**：放在顶栏 logo 右侧，做成带 agent 图标的灰色圆角下拉（「Claude Code ▾」，下方小字或下拉内显示实际厂商；未知用异常色）。点开是带图标的列表，可选。只在 skill、模式页起作用（资源、派发记录页也显示但置灰或隐藏，二选一，以整洁为准）。
4. **模式页 = magpie 的 Agents 页**：每个模式一张卡片，卡片头是模式图标 + 名称 + 默认标记 + 「设为默认」；卡片内每个位置一行：左边「阶段号 · 角色」，右边直接是**灰色圆角的模型选择下拉**（内含厂商 / agent 图标与 `agent/model`，推荐来的加小标记「推荐」），再右边一个小一点的「思考」下拉、一个「备选」图标按钮。选完即保存（调 `config_set_seat`），不再需要「编辑」展开。未指定的位置下拉显示「未选择」并用异常色。
5. **模型选择下拉 = magpie 的 picker**：弹出层顶部搜索框，下面按 agent / provider 分组的列表，每项带图标、模型名、状态（禁用项灰掉）；键盘上下选、回车确定、Esc 关闭；点外部关闭。
6. **数字条 = magpie 的 usage 数字卡**：一条白卡里横向几格，格间竖分隔线；每格大号数字 + 下方灰色小字标签（中文不用大写，用小号灰字即可）。
7. **资源页**：每个 agent 一张卡片，卡片内一行一个模型（不再需要展开才能看，模型多时显示前 8 条 + 「展开其余 N 个」，参照 magpie 的「Show 5 more」）。agent 图标直接显示原色，不加底板（深色主题下深色图标再加底板，浅色主题不加）。
8. **按钮**：主按钮用绿色（新应用图标的绿，浅色约 `#22a565`，深色相应调亮）；次按钮灰底无边框（同 magpie 下拉的灰）。蓝色生效态可以保留给「默认」标记，或统一改为绿色系，二选一以协调为准。
9. **派发记录**：表格放进一张白卡，行间细线；筛选用顶部同款分段切换（全部 / 已完成 / 失败），放在卡片上方左侧。
10. 深色主题同结构换变量；两种主题都只走变量。
