## 1. 参照里要学的东西

- **左侧导航**：顶部应用图标 + 名称；每个导航项「线框图标 + 文字」；选中项浅灰底圆角块；导航区浅灰底，与白色内容区分开。
- **页头一行**：左边页面图标 + 标题 + 灰色小字说明；右边是页面的**橙色实心主按钮**（白字，带「+」或刷新图标），再右边是窗口的最小化 / 最大化 / 关闭，和页头在同一行，不另占一条标题栏。
- **列表行**：白底圆角卡片，1px 浅边框，一行一条。左边 36px 左右的方形图标块（浅边框圆角，里面是标识），中间两行：粗体名称（可带小胶囊标签，如「官方」）+ 灰色一行说明；右边一排**线框图标按钮**（运行 ▷、编辑 ✎、更多 ⋯），悬停有浅底。
- **当前生效的一项**：浅蓝底 + 蓝色 1px 边框，右侧「● 使用中」。
- **分段切换**：浅灰底里的白色选中块（截图里「直连 / 路由 / 聚合」）。
- 整体：浅色为主（深色模式下按同样结构换成深色变量），字号紧凑，留白均匀，没有大片空白。

## 3. 各页按参照改

**资源**
- 页头右侧橙色主按钮「⟳ 重新探测」（执行中显示「探测中…」并禁用）；说明里带「上次探测：<时间>」。
- 每个 agent 一张卡片行：左侧图标块（agent 首字母或简单标识，用中性色，不用品牌图片），名称 + 版本胶囊，灰色说明写模型数与状态（如「12 个模型 · 可用」）；右侧图标按钮「展开 / 收起」。展开后在卡片内列出模型行：模型 id（等宽）+ provider 小字 + 状态；第三方未验证的行右侧图标按钮「▷ 冒烟」（悬停提示「冒烟」，执行中显示转圈或「冒烟中…」）。
- 未发现的模型照旧收起在卡片底部一行。

**模式**
- 每个模式一张卡片行：左侧图标块；名称 + 「默认」时整行用「当前生效」样式（浅蓝底蓝边框，右侧「● 默认」）；灰色说明一行列出人选摘要，如「验收 glm-5.3-flash · 验证 haiku · 验证 gpt-5.6-luna」，人选失效的写成异常色；右侧图标按钮：「☆ 设为默认」（非默认时）、「✎ 编辑」。
- 点「编辑」：在卡片下方展开编辑区（或右侧抽屉，二选一，以整洁为准）：阶段列 + 每个位置的人选 / 思考 / 备选下拉，底部「保存」（橙色主按钮）与「清除」（次按钮）。
- 页头右侧不放主按钮也可以；如放，放「去探测资源」之类真实存在的动作，不造新功能。

**派发记录**
