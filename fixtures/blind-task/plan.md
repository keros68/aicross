# 社区降温点位试验计划

目标是在不增加长期运维负担的前提下，从三个候选社区中选出两处设置夏季临时降温点。先依据 `data.csv` 比较午后平均温度、老年人口占比、步行可达性、既有遮阴和供水条件，形成透明的优先级。第一周完成现场踏勘并核对数据异常；第二周在排名最高的两处各布设一套遮阳、座椅和饮水设施，同时保留一处作为对照。连续四周在相同时段记录温度、使用人数与简短满意度，每周检查设备安全。判断标准为体感温度明显下降、日均使用人数稳定且无重大维护问题。若温度改善但使用率偏低，应先调整位置和开放时段，不直接扩大投入。最终提交点位建议、主要风险、数据局限和下一轮最低成本验证方案；所有结论须区分数据直接支持与合理推断，不补造缺失信息。
