## 3. 配色跟随系统

- 用 `window.matchMedia('(prefers-color-scheme: dark)')` 决定 `document.documentElement` 的 `data-theme`（`light` / `dark`），并监听变化实时切换。`global.css` 已有两套变量（`[data-theme="dark"]`、`[data-theme="light"]`），按需补齐缺的变量。
- 所有页面（含查看页 `RunViewer.css`、`Home.css`、`ConfigPages.css`）只用变量取色，不写死颜色；两种配色下文字与背景的对比都要清楚。
- 视觉纪律照 `docs/PRODUCT.md`「视觉纪律」（单一强调色、1px 边框分块不用阴影、圆角 8 / 4、字号六级、厂商色只做小面积标识）。

## 4. 页面

**模式**：每个模式一张卡片，竖排。

- 卡片头：模式名、「默认」标记（是默认时）、右侧「设为默认」（不是默认时）与「编辑」按钮。
- 卡片体：每个位置一行，`角色` + `agent/model`（等宽）+ 来源小字（本模式指定 / 按角色默认 / 预设写定）；`未指定` 与人选失效（第 5 节）的行用异常色。多阶段的模式在行前标阶段号，或用一条细竖线分隔阶段，表达先后即可，不必画横向流程图。
- 点「编辑」展开卡片：显示 TASK-47 的流程图（可简化为阶段列）与人选 / 思考 / 备选编辑框，保存与清除行为不变；同一时间只展开一张。

**资源**：

- 页头：「上次探测：<时间>」（取 `detected_at`，从未探测显示「尚未探测」）+「重新探测」按钮。上次探测超过 7 天显示一句提示「资源可能已变化，建议重新探测」。
- 每个 agent 一张卡片：名称、版本、状态；模型一行一条，紧凑排列。
- `未发现` 的模型默认收起，卡片底部一行「另有 N 个模型在最近一次探测中未发现」，点开再列出（灰色，不给冒烟按钮）。

**派发记录**：沿用 `Home` 的数据与行为，样式改成与其它页一致的卡片列表。
