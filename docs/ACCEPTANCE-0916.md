给用户实测用。**只列能试的和已知不能试的**，不列实现细节。每条给「怎么试」和「该看到什么」。

起窗口：仓库根目录 `npx --yes -p @tauri-apps/cli@2 tauri dev`（首次要编译一两分钟）。

## 一、这两天按你的反馈改掉的，重点看这些

### 1. 新 tab 不再自动起 codex
**怎么试**：点标签栏的「+」。
**该看到**：出现启动器，让你选 agent 和目录；上次的选择已经填好当预选项，回车即用。**不该看到**：什么都没问就起了一个 codex 会话。

### 2. 左栏四家的版本号形状一致
**该看到**：`2.1.272` / `0.154.0` / `0.42.0` / `0.85.1`，四家都只有版本号。悬停能看到各家 `--version` 的原样输出。

### 3. 行上显示真实模型 ID
**该看到**：Claude 那几行是 `claude-sonnet-5` 这样的真名，不再是 `sonnet`；Kimi 去掉了 `kimi-code/` 前缀；pi 下 `deepseek-flash` 是翻案后的真身。
**悬停详情固定四行**：名字 / 派发名 / 状态 / 来源。派发时要输的那个词在「派发名」里，没丢。

### 4. 折叠不再被切标签推翻
**怎么试**：折起一两家 → 切到「工作区」→ 切回「资源」。
**该看到**：仍然折着。重启应用后也记得。

### 5. 接入页与设置弹窗的 Esc
**怎么试**：打开「管理接入 →」，按 Esc；再打开里面的「手工接入模型」子弹窗，按 Esc。
**该看到**：先关子弹窗，再按才关整页——不会把你在子弹窗里填了一半的东西一起丢掉。设置弹窗按 Esc 也能关。

### 6. 界面缩放
**怎么试**：设置 → 外观 → 五档；或 `Ctrl + =` / `-` / `0`。
**该看到**：整窗缩放不裁切；终端有焦点时快捷键照样生效且不会往终端里漏字符；重启后记得档位。

### 7. 派发建议条
**怎么试**：在总指挥会话里（终端有焦点），从另一个命令行发
`aicross propose --project <你的项目目录> --preset economy --reason "试一下" --text-file <一个文本文件>`
**该看到**：tab 顶部出现一行「建议派发 · 经济模式 · N 路 · Ctrl+Enter 采纳 · 或点右侧按钮」。
- 按 `Esc`：**建议条不动**，Esc 进终端给 codex（这是有意的，不抢终端的键）。
- 按 `Ctrl+Enter` 或点「采纳」：真起流水线。
- 在对话图的输入框里打字回车：**发消息，不会误派发**（这条之前是坏的）。

## 三、试的时候请留意的三件事

1. **哪里让你觉得「还要我先懂一个概念才会用」** —— 这两天四次反馈里有三次是这类。
