# fix-51-r2 资源页可读性（用户 10-06 真机反馈）

用户看了集成窗口：「模型需要处理了是怎么个定义」「不同厂商需要能折叠」。

## 要改

1. **「需处理」改名并可点**：资源页数字卡「需处理」改为「不可用」（= 未发现 + 验证失败 + 未登录 + 额度用尽 的模型数）。点这格数字卡切换为筛选：下面的列表只显示不可用的模型，每行状态胶囊写明原因；再点一次或点「全部」恢复。数字为 0 时不可点。其余几格（agent、可用模型、已验证）不变。
2. **原生模型不显示「0 已验证」**：agent 卡片头的小统计，原生 agent（模型 provider 为空，如 Claude Code、Codex、Kimi）写「N 个模型 · 原生」，不写「已验证」；pi 这类第三方写「N 个模型 · X 已验证 · Y 不可用」（Y 为 0 时省略）。
3. **agent 卡片可折叠**：点卡片头（agent 图标、名称那一行，或右侧的展开图标）展开 / 收起模型列表。默认：有不可用模型的卡片展开，其余收起。折叠状态记在 localStorage（读写包 try/catch）。收起时卡片头仍显示小统计。「展开其余 N 个」与「N 个模型未发现」的行为保留在展开态里。
4. 纯函数补测试：不可用计数与筛选、原生与第三方的小统计文字、默认折叠判定与记忆读写。
