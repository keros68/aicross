# TASK-55（窗口侧）模式介绍与自定义模式入口

**只改 `src-ui/**`。不 commit，不 push，不 npm install。** 契约见同目录 `TASK-55-custom-modes.md`（引擎并行实现）。界面只放名称、数据与动作；模式介绍是数据（来自引擎 `description`），可以显示。

## 1. 模式介绍

- 模式页每张模式卡片：模式名下方一行灰色小字显示 `description`（空则不显示），超长省略、悬停看全文。
- skill 页斜杠命令的模式行：模式名悬停显示 `description`。

## 2. 自定义模式

- 模式页工具行右侧（「一键推荐」旁）加次按钮「新建模式」；「自定义」分组标题右侧也放一个「新建」小按钮。内置模式卡片头加图标按钮「复制为新模式」（以该模式的阶段与位置为初值，名称为「<原名> 副本」）。
- 编辑器（应用内对话框或卡片下方展开，二选一以整洁为准）：
  - 名称输入框、介绍输入框（可空，单行）。
  - 阶段列表：每个阶段一块，块内位置行：角色下拉（出方案 / 执行 / 验收 / 验证 / 拆分）、可见性下拉（共享 / 盲）、写权限下拉（只读 / 单写者 / 独立工作区，传给引擎的值是 只读 / 单写者 / worktree）、思考下拉（沿用 / 关 / 低 / 中 / 高）、删除位置。每块底部「添加位置」；阶段可删除、可「添加阶段」。阶段之间用「→」示意先后。
  - 前端先做同引擎一致的校验并在对应位置显示：名称为空、同阶段多个单写者、没有位置、超过 12 个位置。
  - 「保存」调 `preset_save`；引擎返回的错误显示在编辑器底部。
- 自定义模式卡片头：「编辑」「删除」图标按钮。删除弹应用内确认框（标题「删除模式 <名称>」，确认「删除」），调 `preset_remove`；返回里有受影响项（人选、默认模式、斜杠命令）时，确认框里预先列出（删除前先由前端按当前快照数出：本主 agent 下该模式的人选数、是否为默认、斜杠命令数）。
- 保存或删除后刷新模式页快照与 skill 页斜杠命令列表。

`tauri.ts` 补类型与 `presetSave`、`presetRemove`；`ModeEntry` 加可选 `description`。纯函数测试：编辑器校验、复制为新模式的初值、写权限显示名与引擎值的映射、删除影响计数。
