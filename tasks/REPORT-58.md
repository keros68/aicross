# REPORT-58 新用户走查修正（界面）

只改了 `src-ui/**`，没有 commit、push，没有新增依赖。引擎侧（TASK-57）的新字段与事件按 `TASK-58-newuser-ui.md`「引擎契约」写进 `src-ui/src/tauri.ts`，都是可选字段；旧版引擎缺字段时按原样显示。没有和引擎联调，也没有截图核对界面。

## 逐条改法

1. **资源页初始态（#1、#2）**
   - 「未探测」改为灰底标签，不再标红；agent 卡片头小统计里的「未探测」也不标红。
   - 版本为「未检测」或为空时不显示版本标签。
   - 从未探测时，主按钮写「探测」，资源卡片之上出一条空态条：图标 +「探测本机 agent 与模型」+ 主按钮「探测」。探测过后空态条消失，主按钮回到「重新探测」。
   - 「超过 7 天未探测」的提示条只在探测过之后才出现。

2. **探测进度（#3）**
   - 探测时监听 `resources-detect-progress` 事件，按钮显示「探测中 2/4」；每收到一次事件就重读一次数据，对应卡片随即更新。
   - 还没探测完的 agent，卡片头显示旋转图标。
   - 拿不到事件（浏览器预览）时，按钮退回「探测中…」。

3. **全部测试（#4）**
   - 有未验证第三方模型（provider 不为空）的 agent，卡片头右侧加「全部测试」（图标 + 文字）。
   - 并发 3，逐条调 `resourcesSmoke(agent, model, provider)`；按钮显示「测试中 12/33」，旁边有「取消」。取消后不再发新请求，已发出的照常结束。
   - 结束后重读数据；失败的条目保持各自状态，不弹窗。单条「测试连接」保留。
   - 卡片头拆成左侧可点的展开区域加右侧按钮，避免按钮里套按钮。
   - 限并发执行的逻辑放在新文件 `lib/pool.ts`。

4. **推荐出路（#5）**
   - 一键推荐返回 `unverified` 非空时，推荐提示条逐行追加「pi 有 33 个模型未验证」+ 按钮「去测试」。
   - 点「去测试」跳到资源页：退出「不可用」筛选，展开该 agent 卡片并滚到它。

5. **评审视角（#7）**：位置行的角色名后带上视角，如「验证 · 安全」；视角为空或缺失时只写角色。

6. **模式页（#8）**
   - 「一键推荐」同一时间只出现一处：未配置人选时放在提示条（更醒目），工具行不显示；其余时候在工具行。
   - 「未选择」改为中性虚线框加灰字；人选失效（不可用、未发现等）仍是红框。

7. **skill 页（#10、#11）**
   - 页头不再显示禁用的绿色主按钮：
     - 目标位置由其他软件管理时，显示状态标签「由其他软件管理」。
     - 我们装的且已是最新时，显示「已安装」标签。
     - 可安装、可更新时仍是主按钮。
   - 外部安装且版本低于内置时，状态旁加黄色标签「旧于内置 <内置版本>」，为此新增提醒色变量 `--warn`。
   - 路径照引擎输出显示，界面不拼接斜杠；判断写入位置时的斜杠统一只用于比较，不影响显示。

8. **新建 / 编辑模式（#12）**
   - 每个阶段的位置列表上方加一行列名：角色、可见性、写权限、思考。位置行改成四列网格，与列名对齐。
   - 名称框在输入过或点保存之前不标红。名称没动过时「保存」可以点，点了再校验，不合规就显示错误、不提交。
   - 「添加阶段」的新位置默认「验证 · 盲」。

9. **模型下拉（#13）**：「可用」「已验证」不写状态，只在未验证、未发现等状态时显示。

10. **已存在的命令文件（#14）**：模式行没有已登记命令时：
    - 引擎报告的已存在文件状态为「已写入」：显示该文件的触发写法 +「已存在」标签 + 按钮「登记」，调 `slash_add`，名称取已有文件的名称。
    - 状态为「被占用」：显示红色标签「文件已被占用」，不给按钮。
    - 两者都没有：仍是「生成」。

11. **切页速度（#9）**
    - 资源、skill、模式三页原本就常驻；「派发记录」现在也常驻，只在可见时读取和轮询。
    - 切回任何页都先显示已有数据、后台静默刷新；「读取中…」只在第一次加载时出现。
