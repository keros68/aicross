## 2. 检测失败的 agent 卡片也能折叠

agent 状态不是「可用」（如未安装、探测失败）或没有模型的卡片，卡片头同样可点击折叠 / 展开；展开后显示它的状态与 note（如「未安装」及探测错误）。没有任何可展开内容时，卡片头右侧不显示展开图标、也不响应点击，避免「点了没反应」。

## 3. 主 agent 表达

- 顶栏 logo 右侧固定显示「主 agent」小标签 + 下拉（agent 图标 + 名称），**所有页面都显示**（资源、派发记录页也显示、也可切换；只是这两页内容不随它变化）。

## 4. 清理未发现

- 资源页：存在未发现模型时，工具行出现次按钮「清理未发现（N）」，点了弹应用内确认框（标题「清理 N 个未发现的模型」，确认按钮「清理」），确认后调 `resources_prune(null)`，完成后刷新快照。返回里 `referenced` 非空时，页顶提示条列出「N 个人选引用了已清理的模型」+ 按钮「去模式页」。
- 每个 agent 卡片底部「N 个模型未发现」那一行旁边加小按钮「清理」，调 `resources_prune(agent)`（同样先确认）。
