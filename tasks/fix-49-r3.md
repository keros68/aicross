# fix-49-r3 文案与收尾（用户 10-06 真机反馈）

用户看了 r2：「太多这种口语化表述了」（圈出资源页标题下「先探测本机的 agent 与模型，再到「模式」里选人选。」），并要求修掉 r2 自报的 3 处不足。

## 1. 文案：删掉说明句，只留事实

界面只放名称、数据与动作，不放「该怎么用」的说明句。逐页检查所有可见文字：

- 删掉三页标题下的说明句（资源、模式、派发记录、查看页），以及模式页底部「宿主里的 ai-cross 按这里的设定派发；单次例外在对话里说即可。」这类句子。页头只剩：页面图标 + 标题 +（右侧）动作按钮。
- 资源页的「上次探测」作为数据保留：放在「重新探测」按钮左侧，灰色小字「上次探测 10-06 12:34」（当天只显示时间；未探测显示「尚未探测」）。
- 提示条只写事实 + 动作：「尚未探测资源」+ 按钮「去探测」；「资源超过 7 天未探测」+ 按钮「重新探测」。
- 空状态写成事实：「暂无派发记录」「该筛选下没有记录」，不写建议。
- 未发现分组：「N 个模型未发现」，点开即列出。
- 失效标注：胶囊里「验收 · 未指定」这类保持；不额外加解释句。
- 规则（项目文案规范）：中性简短的说明体；不用第一 / 第二人称、不用劝导语气、不用「即可」「哦」「呢」之类语气词；按钮 2–6 字动词短语；同一概念只用一个词；不出现英文内部词。改完把所有界面字符串过一遍。

## 2. 页头排版

截图里标题与说明贴着窗口上沿，和右侧按钮不在一条线上。页头一行固定高度（约 56px），页面图标、标题、右侧的元信息与按钮、窗口按钮全部垂直居中；与下方概览卡之间 16–20px。

## 3. r2 自报的三处

1. **单阶段多位置的模式编辑区过长**：同一阶段的位置卡改为横向排列（等宽，放不下时折行），编辑框在位置卡下方。
2. **opencode 图标在深色主题下看不清**：图片类图标统一放在一个有底色的圆角容器里（浅色主题白底、深色主题用浅灰底 `--icon-plate` 之类的变量），保证深色图标在两种主题下都可辨。
3. **派发记录长模式名被截断**：模式列只显示模式名（自定义模式显示其名称，不再前缀「自定义模式 ·」），列宽按内容自适应，超长时省略并在悬停时显示全名（`title`）。
