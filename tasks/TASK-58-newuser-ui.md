# TASK-58 新用户走查修正（界面）

来源：`tasks/UX-newuser-20261007.md`（空数据目录走查，14 条）。引擎侧为 TASK-57（在 t46 并行实现），下面「引擎契约」一节是它新增的字段与事件；本工作树里先按契约写类型与界面，引擎代码合并后在集成树联调。

## 引擎契约（TASK-57）

- `resources`：从未探测时 agent 与模型的 `state` 为「未探测」（agent `note`「尚未探测」，模型 `note` 为空）；`detected_at` 为 null。
- 探测进度事件：`resources-detect-progress`，载荷 `{ agent, done, total }`，每个 agent 探测完发一次（各 agent 并行探测）。
- `config_recommend` 输出增加 `unverified: [{ agent, count }]`：各 agent 下可用但未验证、没进推荐候选池的第三方模型数。
- `config show` / `config_snapshot` 每个位置增加 `focus`：评审模式依次为「安全」「性能」「需求覆盖」，其余为空串。
- `skill status` 每个位置增加 `outdated`（外部安装且版本低于内置）；路径在 Windows 上统一反斜杠。
- `slash list` 的 `modes` 每项增加 `existing`：`{ name, state: "已写入" | "被占用", path } | null`，表示还没登记但对应命令文件已存在。

## 要做

1. **资源页初始态（#1、#2）**：「未探测」用中性灰标签，不用红色；版本不显示「未检测」。从未探测时主按钮文字为「探测」，页面顶部（资源卡片之上）放一个空态条：图标 + 「探测本机 agent 与模型」+ 主按钮「探测」；探测过后不再出现，主按钮回到「重新探测」。
2. **探测进度（#3）**：探测中监听 `resources-detect-progress`，按钮显示「探测中 2/4」，各 agent 卡片在完成前显示转圈、完成后更新。事件不可用（浏览器预览）时退回现有「探测中…」。
3. **批量测试连接（#4）**：有未验证第三方模型的 agent 卡片头部加按钮「全部测试」（图标 + 文字），逐条调用 `resourcesSmoke(agent, model, provider)`，并发 3，按钮显示「测试中 12/33」，可取消（停止发新请求）。完成后刷新该卡片；失败的条目保持各自状态，不弹窗。单条「测试连接」保持。
4. **推荐出路（#5）**：模式页推荐提示条在 `unverified` 非空时追加一行「pi 有 33 个模型未验证」+ 按钮「去测试」，跳到资源页并展开该 agent 卡片。
5. **评审视角（#7）**：位置行在角色名旁显示 `focus`（如「验证 · 安全」）；空串时不显示。
6. **模式页（#8）**：只保留一个「一键推荐」（留在提示条或顶部之一，按现有布局选更醒目的一处，另一处去掉）；「未选择」改为中性虚线框 + 灰字，不用红框。真正冲突（不可用、未发现、厂商冲突）仍用红色。
7. **skill 页（#10、#11）**：由其他软件管理时不显示禁用的主按钮，改为状态标签「由其他软件管理」；`outdated` 为 true 时版本旁加黄色标签「旧于内置 1.21.1」。路径显示照引擎输出，不再自行拼接斜杠。
8. **新建 / 编辑模式（#12）**：每个阶段的位置列表上方加一行列名（角色、可见性、写权限、模型 —— 以实际四个下拉为准）；名称框未输入过时不标红，保存时或输入后再校验；新增阶段默认「验证 · 盲」。
9. **模型下拉（#13）**：可用的条目不写「可用」，只在非可用（未验证、不可用、未发现等）时显示状态。
10. **已存在的命令文件（#14）**：`existing` 非空且 `state` 为「已写入」时，该模式行显示「已存在」并把按钮「生成」换成「登记」（调用 `slash_add`，名称取 `existing.name`）；「被占用」时显示「文件已被占用」，不给按钮。
11. **切页速度（#9）**：引擎侧缓存了 ACP 状态；界面侧检查切页时是否每次都重复拉取（资源、配置、skill、slash 各自刷新）。已加载过的页切回时先显示已有数据，后台静默刷新，不再整页「读取中…」。
