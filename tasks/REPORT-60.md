## 逐条改法

1. **评审视角**（`config/ModesPage.tsx`，新增 `config/focus-view.ts`）
   - 位置带视角选项（`focusOptions` 非空）时，角色名旁的视角改成下拉，选项依次是：「默认」、引擎给的可选视角、当前自定义值（不在选项里时补上）、「自定义…」。
   - 选「默认」传空串，恢复默认视角。
   - 选「自定义…」进入行内输入框：回车保存，Esc 或失焦取消；1–20 字，不合规就在框旁显示「视角为空」或「视角超过 20 字」，不提交。
   - 保存调 `config_set_focus(host, mode, index, focus)`，用返回的模式条目刷新本卡片。保存中显示「保存中…」，失败时在该行显示引擎返回的错误。复用人选保存的流程，所以同样有请求序号和卸载保护。
   - `index` 取该位置在本模式所有带视角选项的位置里的序号，按阶段先后从 1 起数。
   - 模式页按主 agent 分开加载，切换主 agent 后整页重读。
   - 没有视角选项的位置仍按 TASK-58 显示「验证 · 安全」这样的文字。

2. **短命令更新**（`config/SlashCard.tsx`、`config/slash-view.ts`）
   - `stale` 为 true 的命令显示黄色标签「待更新」和按钮「更新」，调 `slash_add`，名称、模式、说明都沿用原值。
   - 有任一条待更新时，卡片头「全部生成」旁加「全部更新」：逐条重写，单条失败不中断，错误显示在列表下，结束后用最新返回刷新列表。
   - 与生成、删除、表单共用同一个忙碌状态，同一时间只跑一个。

3. **外部来源**（`config/skill-view.ts`）
   - 外部位置的状态按 `manager` 写成「由 skills.sh 管理」「由 skills-manager 管理」；为空或缺失时仍是「由其他软件管理」。
   - 页头的状态标签用同一套文字。
