# TASK-63 「开始」页（新人首屏）

来源：用户 10-25 反馈，新人用 skill 一开头就不会设置，更习惯图形界面（好设置、好记、方便改）。现有窗口要依次走资源 → skill → 模式三页才能用上，新人不知道从哪开始。skill 1.23.0 起装了 aicross 时按窗口配置派发，窗口里选的会生效。

## 要做

新增页签「开始」，排在最前；没存过页签时默认进它。一页三步，复用现有命令，不改后端：

1. **本机的 AI**：从未探测时给主按钮「探测」（与资源页同一命令与进度事件）；探测过后列出找到的 agent 名称与可用模型数，按钮「重新探测」。
2. **配好**：主 agent 用一排按钮选（与顶栏下拉同一状态）。主按钮「一键配好」依次：skill 未安装或可更新时装到全局（`skill_install`），再一键推荐（`config_recommend`，不带 all，不动手选人选）。配好后显示两行结论：审查用哪个模式、各位置派给谁；干活用哪个模式、各位置派给谁。模式选择与 skill 1.23.0 一致：审用默认模式（盲审 / 评审）否则盲审模式，干活用默认模式（共享 / 经济 / 擂台 / 蜂群）否则经济模式。skill 由其他软件管理时不装，显示管理软件；旧于内置时标黄。按钮「改人选」跳模式页。
3. **怎么用**：回到哪个软件、输入什么，两条示例（审 / 干活），各带复制按钮。调用写法取 `slash_list` 的 `invoke`，读不到时按主 agent 默认写法。

原四页不变。

## 规则

- 文案只放名称、数据、动作；按钮 2–6 字；不用内部词。
- 纯逻辑放 `config/start-view.ts`，补 vitest。
- 不加依赖。
