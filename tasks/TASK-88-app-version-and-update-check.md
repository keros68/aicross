# TASK-88 顶栏显示客户端版本号与手动检查更新

## 问题

1. 客户端窗口没有任何位置显示当前软件版本号，用户无法确认本机运行的是哪一版。
2. `AppUpdateButton` 只在窗口启动时静默查一次 `latest.json`；已是最新版或检查失败（离线、连不上 GitHub、`latest.json` 缺失）时直接返回 `null`，顶栏不显示任何入口，既看不到原因，也无法手动点「检查更新」。

## 要做

1. Rust 侧（`src/server.rs`）：
   - 新增 `app_version` 命令，直接返回当前包版本号，启动即刻可读、不依赖网络。
   - `app_update_check` 改为返回 `{ current, available }`（`available` 为 `null` 或 `{ version, notes }`），保留错误信息供浮层展示。
2. 前端（`src-ui/`）：
   - 顶栏右侧常驻版本与更新入口：无新版时显示 `v<当前版本>`，有新版时切换为醒目的「更新到 X」（下载中显示进度，安装失败显示「更新失败，重试」）。
   - 点击入口展开浮层：显示当前版本、检查结果（「已是最新版本」/「正在检查更新…」/ 检查失败原因 / 可更新版本与更新说明），提供「检查更新」按钮与（有新版时的）「更新」按钮。
   - 启动自动检查失败时顶栏保持安静不打扰，点开浮层可看到失败原因并手动重试。
   - 视图状态与文案拆到纯函数模块并补齐单元测试。
3. 文档（`docs/MANUAL.md`）：同步更新「软件更新」一节说明。

## 不做

- 不把 GitHub 更新检查绑进顶栏「刷新」按钮（页面刷新只读本机数据，避免离线时拖慢刷新或误报刷新失败）。
- 不改打包脚本与版本号，不发 Release。
