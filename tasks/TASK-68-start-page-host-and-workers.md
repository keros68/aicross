# TASK-68 开始页拆成主 agent 与副 agent

用户 10-28 反馈：开始页第 1 块「本机的 AI」说法口语化，内容费解。这一块把能派发的 agent 和只能当主 agent 的软件混在一起，选主 agent 又在第 2 块，用户读不出该怎么用。

## 要做

1. 开始页分四块：
   - 主 agent：你和 AI 对话的软件，ai-cross skill 装在这里。探测按钮、选在哪个软件里用、skill 状态都放这里。
   - 副 agent：被派去干活、审查的。每家一行，写可用与未验证的模型数，以及含哪几家的模型；当前主 agent 也在其中时标出。「详情」进资源页。
   - 配好：一键配好，审与干活各派给谁。
   - 怎么用。
2. 探测仍是一次，同时得出主 agent 与副 agent。
3. 资源输出的模型带 `vendor`，开始页据此写系列名（Anthropic → Claude 等）；系列名全写，不截断。
4. `docs/MANUAL.md` 开始一节与术语表（主 agent、副 agent）。

## 完成条件

- 单元测试：副 agent 的列出范围、计数、系列名排序与当前主 agent 标记；说明文字。
- 窗口里看过四块的显示。
